# 在线商城后端设计

## 范围与架构

系统采用 NestJS 模块化单体架构，对外提供版本化 REST API。业务按 `auth`、`users`、`products`、`orders` 分模块；Prisma 统一访问 MySQL，Redis 承担商品详情及热门列表缓存。请求通过全局参数校验管道后进入控制器，认证接口由 JWT Guard 解析身份，授权接口再由 Roles Guard 校验角色。

金额统一用整数分存储，避免浮点误差。订单创建在一个数据库事务中完成：校验商品状态与库存、原子扣减库存、创建订单与订单明细快照。订单明细保存下单时的商品名和单价，避免商品后续修改影响历史订单。

## 缓存、错误与安全

商品详情键为 `product:detail:{id}`，热门列表键包含分页参数，均设置 TTL。商品新增、修改、上下架后清理相关缓存；读取缓存失败时回退 MySQL，确保 Redis 故障不会破坏主业务。统一异常响应包含状态码、错误信息、路径和时间。

密码使用 bcrypt 哈希，JWT 只保存用户 ID、邮箱和角色。密钥通过环境变量注入，不进入仓库。Helmet 设置基础安全响应头，DTO 白名单阻止未声明字段进入业务层。

## 测试与部署

单元测试覆盖认证、缓存和订单事务的关键分支；端到端测试覆盖健康检查、注册登录、商品读取和下单主链路。Docker Compose 同时编排 API、MySQL 和 Redis，API 启动前执行生产迁移。生产部署使用非 root Node 用户，并配置服务健康检查和持久化数据卷。
